
# Pong Game — CAP3032 Final Project

A classic Pong game developed using Processing (JAVA).

## Game Design

The image below represents our planned game layout, including the main menu, difficulty selection, gameplay, and controls.

![Pong Game Design](pong_design.png)

## Planned Features

- Player versus AI
- Easy and Hard difficulty levels
- Keyboard-controlled paddle
- Score tracking (first to 5 points wins) - Subject to change
- Background music and collision sound effects
- Start, Quit, and Restart options
